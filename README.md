# Gestão Kátia Festas

Protótipo de interface (frontend único, HTML/CSS/JS) do sistema de gestão da Kátia Festas.

## Como usar

Abra o arquivo `index.html` em qualquer navegador — não precisa de servidor nem build.

> Protótipo de interface — dados de exemplo. Nada é salvo de verdade; atualizar a página restaura os dados iniciais.
